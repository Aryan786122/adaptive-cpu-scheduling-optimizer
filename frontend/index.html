The Core Scheduling Problem

“Heavy background jobs can delay short interactive tasks. Can adaptive CPU scheduling reduce that delay?”

Under non-preemptive arrival-order scheduling, short user requests are forced to wait for long-running batches to conclude (The Convoy Effect). Our proposed Adaptive Scheduler prioritizes latency-critical requests with bounded cooperative preemption (~15ms checkpoints) and uses dynamic aging to eliminate background task starvation.

Baseline Algorithm

First-Come, First-Served (FCFS)

  • Strict arrival-order execution queue
  • Non-preemptive dispatch within managed workload
  • Exhibits severe Convoy latency for arriving interactive tasks
  • Zero awareness of workload latency sensitivity
Proposed Solution

Adaptive Priority Scheduling with Aging

  • Workload-aware priority dispatch (Interactive > Background)
  • Cooperative preemption checkpoints at bounded ~15ms intervals
  • Dynamic aging elevation: prevents background starvation
  • Directly informed by host CPU telemetry observations
